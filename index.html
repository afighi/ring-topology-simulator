Token Ring Topology Simulation Guide

What is Token Ring Topology?

A Token Ring network is a type of local area network (LAN) where all devices are connected in a ring. Here's how it works:

  • A special data packet called a 'token' circulates around the ring
  • To send data, a device must first capture the free token
  • The device attaches its data and the recipient's address to the token
  • Each device checks if the token is addressed to it
  • If not addressed to it, the device passes the token to the next device
  • If addressed to it, the device copies the data and sends an acknowledgment back
  • The source device then frees the token for others to use

Quick Start Guide

1. Basic Controls

  • Add PC: Click "Add Node" to add new PCs (max 12)
  • Remove PC: Click the ❌ button next to any PC
  • Power On/Off: Click the power button next to any PC
  • Break Connection: Click directly on any connection line

2. Sending Data

  1. Select a source PC from the "Source" dropdown
  2. Select a destination PC from the "Destination" dropdown
  3. Click "Send Node" to start the transmission
  4. Watch the token carry the data around the ring

3. Network Management

  • Break All: Breaks all connections in the ring
  • Restart All: Restores all connections and turns PCs back online
  • Activity Log: Shows all network events on the left panel
  • Network Stats: Displays real-time network information

4. Important Notes

  • The ring needs at least 2 PCs to function
  • Maximum 12 PCs allowed in the ring
  • All PCs must be online for the ring to work properly
  • Broken connections prevent data transmission
  • Use "Restart All" to fix broken connections and offline PCs
